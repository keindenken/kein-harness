What people actually put in a standing prompt

4,659 SKILL.md files were pulled from public GitHub repositories and a stratified shortlist of 640 was read in full, one question each: does this file assert anything about its domain that could not have been derived from knowing the domain exists? Rows are ranked by how many times the file has been revised, because a file corrected twenty times was corrected by something.

Removal rate

25,718 lines removed against 57,462 added. Deletion is routine — it just never outpaces addition.

Measure themselves

Only trailofbits/skills reports an arm-versus-arm result for its own prompt.

The stratum chips are the sampling frame, not a judgement — 70 files were taken from each domain bucket by specificity score, plus 80 control files drawn from below the median so the score could be checked against the model's own reading. It did not survive that check: the top band and the control band scored almost identically, so the model's numeric rating was discarded and only its claim is shown here. Revision counts come from blobless clones of 244 repositories. Full method and the rest of the results are in .agents/kein/research/260811-github-skill-corpus/findings.md.
